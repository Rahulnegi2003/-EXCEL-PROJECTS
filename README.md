# E-commerce Sales Analysis using Excel 📊

## 📌 Project Overview

This project focuses on analyzing an **E-commerce sales dataset using Microsoft Excel**. The objective is to clean the raw sales data, perform exploratory analysis, create pivot tables, and identify important sales trends and business insights.

The analysis helps understand **revenue performance, customer orders, product categories, geographical sales, monthly trends, discounts, order status, payment methods, and sales performance**.

## 📂 Dataset

The dataset contains e-commerce order information, including:

* Order ID
* Order Date
* Category
* Product
* State
* Quantity
* Unit Price
* Discount
* Order Status
* Payment Mode
* Sales Channel
* Order Amount

### Dataset Size

* **Raw records:** 1,112
* **Cleaned records:** 1,101
* **Number of columns:** 12+ derived analytical columns

## 🧹 Data Cleaning

The raw dataset was cleaned in Excel by:

* Removing duplicate/invalid records
* Handling missing values
* Standardizing date formats
* Standardizing discount values
* Creating a **Month** column
* Creating a **Sales Bucket** column
* Checking data consistency before analysis

## 📊 Analysis Performed

The following analyses were performed using **Excel Pivot Tables and formulas**:

### 1. Overall Sales Performance

* Total number of orders
* Total revenue
* Average order value
* Sales performance

### 2. Category Analysis

Analyzed revenue generated by different product categories such as:

* Beauty
* Books
* Fashion
* Home
* Electronics
* Other categories present in the dataset

### 3. State-wise Analysis

Compared sales revenue across different Indian states to identify high-performing and low-performing regions.

### 4. Monthly Sales Trend

Analyzed sales performance month-by-month to identify:

* High-sales months
* Low-sales months
* Seasonal trends
* Changes in revenue over time

### 5. Order Status Analysis

Analyzed orders based on their status, including:

* Delivered
* Pending
* Returned
* Cancelled

### 6. Payment Mode Analysis

Compared sales/orders across different payment methods such as:

* COD
* Credit Card
* Debit Card
* Other available payment methods

### 7. Sales Channel Analysis

Compared performance across different sales channels, such as website and other available channels.

## 📈 Key Findings

The analysis generated approximately:

* **1,100 orders**
* **₹1.34 Crore total revenue**

The analysis also identified differences in revenue across **product categories, states, months, payment modes, and order statuses**.

The Pivot Tables were used to identify the highest-performing categories and states and to understand monthly revenue trends.
